🎬 Editor de Videos AIDA

Tutorial paso a paso para crear videos profesionales

1
Instalar Librería

Abre PowerShell y ejecuta este comando:

pip install moviepy

Espera 2-3 minutos a que termine la instalación.

✅ Cuando veas "Successfully installed moviepy" = ¡LISTO!
📌 Solo necesitas hacer esto UNA VEZ

2
Crear Carpeta de Videos

Crea una carpeta llamada "videos_originales" en:

Ubicación:
C:\EDITOR_VIDEOS_BUEN_CERDITO\videos_originales\

Cómo hacerlo:
1. Ve a C:\EDITOR_VIDEOS_BUEN_CERDITO\
2. Click derecho → Nuevo → Carpeta
3. Nómbrala: videos_originales
4. ¡Listo!

3
Agregar Videos

Copia tus videos MP4 a la carpeta videos_originales

⚠️ Importante:
• Formatos soportados: MP4, AVI, MOV
• Duración recomendada: 2-10 segundos cada video
• Total ideal: 15-60 segundos
• Nombres: sin caracteres especiales (ñ, tildes, etc)

Ejemplos de nombres válidos:

1.mp4 2.mp4 3.mp4
O también:
producto.mp4 montaje.mp4 llamada.mp4

4
Agregar Música (Opcional)

Descarga una música MP3 y cópiala a:

Ubicación:
C:\EDITOR_VIDEOS_BUEN_CERDITO\musica_fondo.mp3

Dónde descargar música gratis:

  • 🎵 Pixabay Music (pixabay.com/music)
  • 🎵 YouTube Audio Library
  • 🎵 Bensound (bensound.com)
ℹ️ Nota: Si no tienes música, el script igualmente crea el video sin ella

5
Ejecutar el Script

Opción A: Click derecho

1. Ve a: C:\EDITOR_VIDEOS_BUEN_CERDITO\ 2. Click derecho en el espacio vacío 3. "Abrir PowerShell aquí"

Opción B: Desde PowerShell

cd C:\EDITOR_VIDEOS_BUEN_CERDITO

Luego ejecuta:

python editor_videos_aida.py

Presiona ENTER y espera...

6
Ver el Resultado

Cuando termine, abre:

Archivo generado:
C:\EDITOR_VIDEOS_BUEN_CERDITO\video_final.mp4

Haz doble click para abrir en VLC o tu reproductor predeterminado

✅ ¡Video listo para Facebook Ads!
🚀 Cópialo y publícalo en tu campaña

7
Personalizar Textos (Opcional)

Si quieres cambiar los textos AIDA:

1. Abre el archivo:

C:\EDITOR_VIDEOS_BUEN_CERDITO\editor_videos_aida.py

2. Con Notepad o VS Code

3. Busca esta sección (línea ~60):

TEXTOS_AIDA = { "atencion": "🐷 ¡MIRA ESTO!", "interes": "Cemitas hechas como en casa", "deseo": "Frescas, deliciosas, irresistibles", "accion": "Pide por WhatsApp: +52 222 278 1310" }

4. Reemplaza con tus textos:

TEXTOS_AIDA = { "atencion": "Tu primer texto", "interes": "Tu segundo texto", "deseo": "Tu tercer texto", "accion": "Tu llamada a acción" }

5. Guarda (Ctrl+S) y ejecuta de nuevo

✓
Checklist Rápido

Antes de ejecutar:

⚠️
Solucionar Problemas

Error: "No module named 'moviepy'" Ejecuta: pip install moviepy
Error: "No videos found" Verifica que exista videos_originales\ con videos dentro
Error: "Error loading video" Convierte los videos a MP4, sin caracteres especiales
Tarda mucho (15+ min) NORMAL - Espera sin cerrar PowerShell
